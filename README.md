# Slums MC public distribution

This repository contains the sanitized, read-only client Packwiz distribution for Slums MC. It is intentionally separate from the private Packwiz source repository.

Packwiz update URL:

`https://joshhmann.github.io/slums-mc-distribution/stable/client/pack.toml`

The friend installer remains distributed through NextExplorer. It will configure existing and new Prism instances to use the Packwiz URL above for client updates.

Only the client distribution is public. Server source, worlds, panel state, and deployment credentials are not stored here.
